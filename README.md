# Sunscreen Checker

This is my first project using an API.

It uses the OpenUV API to get the current UV index for the user's location and then gives a simple sunscreen recommendation based on that value.

## Files
- index.html — main page
- style.css — styling
- script.js — gets geolocation and calls the API

## How to run
- Open `index.html` in a browser with geolocation support.
- Or serve the folder locally:

```bash
python -m http.server 8000
```

Then open http://localhost:8000 in the browser.

## Note
This is a beginner-friendly project to learn how to work with APIs in a real web app.
